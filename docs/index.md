# Komodo Provider

Terraform provider for managing Komodo resources via the Komodo API.

## Example Usage

```terraform
provider "komodo" {
  server   = "https://your-komodo-server.com"
  username = "your-username"
  password = "your-password"
}
```

## Authentication

The provider supports authentication via username and password. You can configure these in three ways:

### 1. In the provider block

```terraform
provider "komodo" {
  server   = "https://your-komodo-server.com"
  username = "your-username"
  password = "your-password"
}
```

### 2. Via environment variables

```bash
export KOMODO_SERVER="https://your-komodo-server.com"
export KOMODO_USERNAME="your-username"
export KOMODO_PASSWORD="your-password"
```

### 3. Mixed approach

```terraform
provider "komodo" {
  server = "https://your-komodo-server.com"
  # username and password will be read from environment variables
}
```
